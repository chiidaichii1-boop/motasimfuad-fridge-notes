One funny passive-aggressive note a smart fridge leaves for its owner.

## Run

```sh
python3 main.py
```

`main.py` writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). Stdlib only, no network, deterministic.

## The note

> The door was open 47 seconds. The ice maker saw everything. The yogurt expired Tuesday and asked me to stop telling it about you.
